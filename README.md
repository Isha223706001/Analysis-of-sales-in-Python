Diwali Sales Data Analysis

 📊 Project Overview
This project analyzes Diwali sales data using Python to understand customer purchasing behavior.

🛠 Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

🔍 Key Analysis
- Data cleaning using dropna() and drop()
- Exploratory Data Analysis (EDA)
- Gender-based purchasing comparison
- Product category analysis
📌 Key Insight
Married women aged 26–35 are the most active buyers, mainly purchasing food, clothing, and electronics.
